# Icon notice

The game icons in this folder are Capcom's artwork. They are used as-is, in an unofficial, non-commercial fan
tool (MH4U Set Builder) that is not affiliated with or endorsed by Capcom. Monster Hunter and all related names and
artwork are the property of Capcom Co., Ltd.

Source: supplied by the project owner as white-base versions of the in-game icons (black outline, white main
color, gray shading). Rarity and jewel colors are applied in the UI by tinting.

These files will be removed on request. If you represent Capcom, please open an issue.

Layout: `armor/<slot>.png`, `weapons/<weapon-class>.png` (kebab-case of the class name in `weapons.json`),
`misc/decoration.png`, `misc/charm.png`.
