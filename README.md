# MH4U-Set-Builder

An unofficial, free, client-side set builder for Monster Hunter 4 Ultimate.
Static site, hosted on GitHub Pages; everything runs in your browser.

Unofficial fan project, not affiliated with or endorsed by Capcom.

## Development

Requires Node 24 (see `.nvmrc`).

```bash
npm ci --ignore-scripts   # install exactly what the lockfile says
npm run dev               # dev server
npm test                  # unit tests (vitest)
npm run build             # typecheck + production build into dist/
```

Other scripts: `npm run lint`, `npm run typecheck`, `npm run preview`.
The game data in `public/data/` is generated by `tools/convert.py` (see `docs/data-format.md`); do not edit it by hand.
